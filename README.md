## Overview
This repository contains the complete 3D CAD modeling, parametric design assemblies, and technical engineering documentation for a modular wind tunnel test section and front mesh cartridge assembly. 

Designed at the **University of Arkansas**, this project focuses on optimizing internal geometric flow paths, enabling rapid component interchangeability for aerodynamic flow conditioning, and preparing manufacturing-ready documentation.

---

## 🛠️ Key Design Features
* **Modular Front Mesh Cartridge:** Modular housing engineered for rapid installation and swapping of flow-conditioning mesh screens during testing.
* **Flow Geometry Optimization:** Radii and sectional transitions designed to reduce boundary layer growth and minimize flow turbulence ahead of the test section.
* **Manufacturing-Ready Drawings:** Detailed technical drawings prepared according to ASME/ISO drafting standards, complete with section views, dimensions, and baseline tolerances.
* **Multi-Format Export:** Includes native SolidWorks files as well as universal `.STEP` and `.PDF` formats for cross-platform accessibility.
